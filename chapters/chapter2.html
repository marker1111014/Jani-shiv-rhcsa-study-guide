從命令列管理檔案

掌握核心檔案系統操作技巧，包含瀏覽目錄、建立檔案、複製、移動與刪除。 學習使用強大的命令列工具高效率地管理檔案與目錄。

🎯 簡介

檔案管理是 Linux 系統管理員的核心技能。了解如何瀏覽檔案系統、建立與修改檔案，以及有條理地組織資料，對於日常系統管理作業至關重要。

您將學到的關鍵技能包含：

  • 理解 Linux 檔案系統階層架構
  • 使用 cd、pwd 與 ls 瀏覽目錄
  • 建立、複製、移動與刪除檔案及目錄
  • 使用萬用字元進行高效率的檔案操作
  • 建立並管理符號連結與硬連結

🗂️ Linux 檔案系統階層架構

Linux 遵循檔案系統階層標準（Filesystem Hierarchy Standard，FHS），該標準定義了類 Unix 作業系統中的目錄結構與各目錄所存放的內容。

重要目錄一覽

目錄 用途說明
/ 根目錄（整個階層架構的最頂端）
/home 一般使用者的家目錄
/root root 超級使用者的家目錄
/etc 系統與服務設定檔
/var 變動資料（系統日誌、資料庫、快取）
/usr 使用者程式與公用程式
/tmp 暫存檔案
/dev 裝置檔案（硬體設備介面）
📘 注意

絕對路徑以 / 開頭（例如 /home/student）。相對路徑不以 / 開頭，而是相對於您目前所在的目錄。

🧭 瀏覽檔案系統

pwd - 顯示目前工作目錄

顯示您目前在檔案系統中所處的路徑位置：

[student@localhost ~]$ pwd
/home/student

cd - 切換目錄

切換至不同的目錄：

# 前往家目錄
cd

# 前往指定目錄
cd /etc

# 回到上一層目錄
cd ..

# 回到上一個所在的目錄
cd -

# 往上移動兩層父目錄
cd ../..

# 前往指定使用者的家目錄
cd ~student
💡 提示

輸入路徑時善用 Tab 自動補齊功能。只要輸入前幾個字元並按下 Tab，系統就會自動補齊完整名稱。

ls - 列出目錄內容

顯示目錄中的檔案與子目錄：

# 基本清單顯示
ls

# 長格式（詳細資訊）
ls -l

# 顯示隱藏檔案（以 . 開頭）
ls -a

# 以人類易讀的單位顯示檔案大小
ls -lh

# 依修改時間排序
ls -lt

# 反向排序
ls -lr

# 組合多個選項
ls -lah

解讀 ls -l 的輸出欄位

-rw-r--r--. 1 student student 1234 Nov 14 10:30 file.txt
│││││││││││ │ │       │       │    │         │
│││││││││││ │ │       │       │    │         └─ 檔案名稱
│││││││││││ │ │       │       │    └─ 最後修改時間
│││││││││││ │ │       │       └─ 檔案大小（位元組）
│││││││││││ │ │       └─ 擁有群組
│││││││││││ │ └─ 擁有者
│││││││││││ └─ 硬連結數量
│└┬┬┬┬┬┬┬┬┬─ SELinux 安全脈絡指示符
│ │││││││└─ 其他使用者權限 (r--)
│ │││└┬┬─ 群組權限 (r--)
│ └┬┬─ 擁有者權限 (rw-)
└─ 檔案類型（- = 一般檔案，d = 目錄）

📝 管理檔案與目錄

建立檔案與目錄

touch - 建立空白檔案

# 建立一個新檔案
touch newfile.txt

# 一次建立多個檔案
touch file1.txt file2.txt file3.txt

# 更新現有檔案的時間戳記
touch existingfile.txt

mkdir - 建立目錄

# 建立目錄
mkdir mydir

# 一次建立多個目錄
mkdir dir1 dir2 dir3

# 視需要一併建立上層父目錄
mkdir -p parent/child/grandchild

# 建立目錄的同時設定權限
mkdir -m 755 securedir

複製檔案與目錄

cp - 複製

# 複製檔案
cp source.txt destination.txt

# 複製檔案至指定目錄
cp file.txt /tmp/

# 複製多個檔案
cp file1.txt file2.txt /tmp/

# 遞迴複製目錄及其內容
cp -r sourcedir/ destdir/

# 保留檔案屬性（權限、時間戳記等）
cp -p file.txt backup.txt

# 互動模式（覆寫前先詢問）
cp -i file.txt existing.txt

# 顯示詳細輸出
cp -v file.txt /tmp/

移動與重新命名

mv - 移動／重新命名

# 重新命名檔案
mv oldname.txt newname.txt

# 移動檔案至目錄
mv file.txt /tmp/

# 移動多個檔案
mv file1.txt file2.txt /tmp/

# 移動或重新命名目錄
mv olddir/ newdir/

# 互動模式（覆寫前詢問）
mv -i file.txt /tmp/

# 不覆寫現有檔案
mv -n file.txt /tmp/

刪除檔案與目錄

rm - 移除檔案或目錄

# 刪除檔案
rm file.txt

# 刪除多個檔案
rm file1.txt file2.txt

# 互動式刪除（逐一確認）
rm -i file.txt

# 強制刪除（不詢問且忽略不存在的檔案）
rm -f file.txt

# 遞迴刪除目錄及其內容
rm -r directory/

# 顯示詳細輸出
rm -v file.txt
⚠️ 警告

使用 rm -rf 時請務必極度謹慎。Linux 命令列沒有垃圾桶或資源回收筒機制，檔案一旦刪除便難以復原！

rmdir - 移除空目錄

# 刪除空目錄
rmdir emptydir/

# 若上層目錄在移除子目錄後也變為空目錄，則一併刪除
rmdir -p parent/child/

萬用字元與樣式比對

樣式 比對規則 範例
* 零個或多個任意字元 ls *.txt
? 單一字元 ls file?.txt
[abc] 括號內的任一字元 ls file[123].txt
[!abc] 不在括號內的任一字元 ls file[!0-9].txt
{a,b} 大括號展開（Brace expansion） cp file.{txt,bak}

萬用字元使用範例

# 列出所有 .txt 檔案
ls *.txt

# 複製所有 .conf 設定檔
cp /etc/*.conf ~/backup/

# 刪除所有以 'temp' 開頭的檔案
rm temp*

# 列出副檔名為單一字元的檔案
ls *.?

# 建立備份複本
cp file.txt{,.bak}

🔗 使用連結（Links）

硬連結（Hard Links）

硬連結是為現有檔案建立的另一個目錄項目。兩個檔案名稱會指向磁碟上的同一份資料。 

# 建立硬連結
ln /path/to/original /path/to/link

# 範例
ln /tmp/original.txt /home/student/link.txt

硬連結特性

  • 無法跨越不同的檔案系統
  • 無法連結至目錄
  • 刪除其中一個連結不會影響其他連結與檔案內容
  • 所有連結皆具有完全對等的地位
  • 擁有相同的 inode 編號

符號連結（軟連結，Symbolic / Soft Links）

符號連結是一種特殊檔案，透過路徑名稱來指向另一個檔案或目錄（類似捷徑）。 

# 建立符號連結
ln -s /path/to/original /path/to/link

# 範例
ln -s /usr/share/doc ~/Documents/shared-docs

# 建立指向目錄的符號連結
ln -s /var/log ~/logs

符號連結特性

  • 可以跨越不同的檔案系統
  • 可以連結至目錄
  • 若目標檔案被刪除，符號連結將會失效（斷裂）
  • 擁有各自獨立的 inode 編號
  • 在 ls -l 輸出中檔案類型顯示為 l

操作步驟：建立並驗證連結

  1. 建立原始檔案： 
    echo "Original content" > original.txt
  2. 建立硬連結： 
    ln original.txt hardlink.txt
  3. 建立符號連結： 
    ln -s original.txt symlink.txt
  4. 使用 ls -li 進行驗證： 
    ls -li *.txt
  5. 透過修改原始檔案來測試效果： 
    echo "Modified" >> original.txt
cat hardlink.txt
cat symlink.txt
💡 提示

使用 ls -i 可以查看檔案的 inode 編號。指向同一個檔案的硬連結會共用相同的 inode。

📝 練習題

第 1 題：哪一個指令可以在需要時自動建立上層父目錄？

  • A) mkdir -r parent/child
  • B) mkdir -p parent/child
  • C) mkdir -a parent/child
  • D) mkdir parent/child
解答：B) mkdir -p parent/child
-p 選項會在必要時一併建立上層父目錄，而且不會產生錯誤訊息。

第 2 題：硬連結與符號連結之間有什麼差異？

  • A) 硬連結可以跨越檔案系統
  • B) 符號連結共用相同的 inode
  • C) 硬連結無法連結至目錄
  • D) 符號連結存取速度較快
解答：C) 硬連結無法連結至目錄
硬連結直接指向相同的 inode，因此無法連結至目錄，也無法跨越不同的檔案系統。

第 3 題：哪一個萬用字元可以精確比對單一字元？

  • A) *
  • B) ?
  • C) []
  • D) {}
解答：B) ?
? 萬用字元代表精確比對一個字元，而 * 則代表比對零個或多個字元。

第 4 題：'cp -r' 的作用是什麼？

  • A) 反向順序複製
  • B) 遞迴複製（包含子目錄）
  • C) 複製並刪除來源檔案
  • D) 以 root 權限複製
解答：B) 遞迴複製（包含子目錄）
-r 選項會啟用遞迴複製，是複製整個目錄及其內容時的必要參數。

第 5 題：哪一個目錄存放系統設定檔？

  • A) /var
  • B) /usr
  • C) /etc
  • D) /opt
解答：C) /etc
/etc 目錄存放系統與各類應用程式的設定檔。
