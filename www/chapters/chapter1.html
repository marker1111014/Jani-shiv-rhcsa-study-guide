存取系統與取得支援

學習如何透過本機與遠端終端機存取並操作 Linux 系統。 本章涵蓋使用 SSH 連線至 RHEL 系統、操作命令列介面，以及查閱系統文件等核心技能。

📋 本章目錄

  • 簡介
  • 存取本機系統
  • 使用 SSH 存取遠端系統
  • Bash Shell 基礎
  • 存取系統文件
  • 練習題

🎯 簡介

能夠存取並操作 Linux 系統是系統管理最基本的能力。 身為系統管理員，您會需要從本機（實體主機端）以及遠端（透過網路使用 SSH）連線至伺服器。 了解這些存取方式並知道如何在需要時尋找說明資源，是邁向 RHCSA 認證的重要第一步。

本章將帶您掌握以下核心技能：

  • 使用虛擬主控台登入 Linux 系統
  • 使用 SSH 安全地連線至遠端系統
  • 操作 Bash Shell 環境
  • 查閱系統內建的文件與說明資源
  • 了解指令語法與選項結構
📘 注意

在本指南中，指令都會搭配輸出範例進行說明。建議您在自己的 RHEL 9 系統上實際練習這些指令，以加深學習印象。

🖥️ 存取本機系統

虛擬主控台（Virtual Consoles）

RHEL 9 提供多個虛擬主控台，讓您可以在單一實體系統上同時擁有多個獨立的登入工作階段。 預設情況下，系統會提供六個文字介面的虛擬主控台。

切換虛擬主控台

請使用以下鍵盤快捷鍵在各個虛擬主控台之間切換：

  • Ctrl+Alt+F1 至 Ctrl+Alt+F6 - 存取文字主控台 1 至 6
  • Ctrl+Alt+F1 - 返回圖形化桌面環境（若有安裝）
💡 提示

當圖形介面無回應，或是您需要同時開啟多個工作階段時，虛擬主控台是進行疑難排解的絕佳工具。

登入流程

當您進入虛擬主控台時，將會看到登入提示畫面：

Red Hat Enterprise Linux 9.3 (Plow)
Kernel 5.14.0-362.el9.x86_64 on an x86_64

localhost login: _

操作步驟：登入虛擬主控台

  1. 按下 Ctrl+Alt+F2 切換至第 2 個虛擬主控台
  2. 在登入提示處輸入您的使用者名稱，並按下 Enter
  3. 輸入您的密碼並按下 Enter（輸入時螢幕上不會顯示密碼字元）
  4. 登入成功後，您將會看到命令提示字元
[student@localhost ~]$ _
⚠️ 警告

密碼區分大小寫。輸入密碼時請確認 Caps Lock 大寫鎖定鍵已關閉。

🔐 使用 SSH 存取遠端系統

什麼是 SSH？

安全外殼協定（Secure Shell，簡稱 SSH）是一種加密網路協定，可在不安全的網路中提供安全的傳輸通道。 SSH 會加密所有傳輸流量（包含密碼在內），以防範網路竊聽與連線劫持。

基本 SSH 語法

ssh username@hostname

或者使用 IP 位址連線：

ssh username@192.168.1.100

SSH 連線範例

[student@workstation ~]$ ssh user@servera.example.com
The authenticity of host 'servera.example.com (192.168.1.10)' can't be established.
ECDSA key fingerprint is SHA256:1A2B3C4D5E6F7G8H9I0J.
Are you sure you want to continue connecting (yes/no/[fingerprint])? yes
Warning: Permanently added 'servera.example.com' (ECDSA) to the list of known hosts.
user@servera.example.com's password: 
[user@servera ~]$
📘 注意

首次連線至某部主機時，SSH 會要求您驗證該主機的指紋（Fingerprint），以防止中間人攻擊。請輸入 "yes" 繼續連線。

SSH 金鑰驗證

為了提升安全性與操作便利性，您可以使用 SSH 金鑰來取代密碼登入。這需要先建立一組公鑰／私鑰金鑰對。

操作步驟：設定 SSH 金鑰驗證

  1. 產生 SSH 金鑰對： 
    ssh-keygen -t rsa -b 4096
  2. 按下 Enter 接受預設的儲存路徑（~/.ssh/id_rsa）
  3. 可依需求選擇是否輸入密語（Passphrase）以增加安全性
  4. 將公鑰複製到遠端伺服器： 
    ssh-copy-id user@servera.example.com
  5. 測試連線（此時應不會再要求輸入密碼）： 
    ssh user@servera.example.com

常用 SSH 選項

選項 說明
-p PORT 連線至指定的連接埠
-v 詳細輸出模式（有助於疑難排解）
-X 啟用 X11 轉發以執行遠端圖形應用程式

結束 SSH 工作階段

若要中斷 SSH 連線，可使用下列任一方式：

exit
# 或
logout
# 或按
Ctrl+D

⌨️ Bash Shell 基礎

認識命令提示字元

預設的 Bash 命令提示字元會顯示許多實用資訊：

[student@localhost ~]$

各部分說明如下：

  • student - 目前的使用者名稱
  • localhost - 系統的主機名稱
  • ~ - 目前所在的目錄（~ 代表家目錄）
  • $ - 一般使用者的提示字元（root 使用者則顯示為 #）

基本指令結構

command [options] [arguments]

範例：

ls -l /etc
  • ls - 指令（列出目錄內容）
  • -l - 選項（長格式顯示）
  • /etc - 參數（要列出內容的目標目錄）

常用 Bash 快捷鍵

快捷鍵 操作
Tab 自動補齊指令與檔案名稱
Ctrl+C 取消目前正在執行的指令
Ctrl+D 結束並離開目前的 Shell
Ctrl+A 移動游標至該行開頭
Ctrl+E 移動游標至該行結尾
↑/↓ 瀏覽歷史執行過的指令
💡 提示

Tab 自動補齊是 Bash 中最實用的功能之一。按一次 Tab 可自動補齊名稱，連按兩次則可列出所有可能的補齊項目。

📚 存取系統文件

Man 手冊頁（Man Pages）

線上手冊（Manual pages，簡稱 man pages）是 Linux 指令與系統呼叫最主要的文件來源。

基本用法

man command_name

範例：

man ls

瀏覽 Man 手冊頁

按鍵 操作
Space 向下捲動一頁
b 向上捲動一頁
/pattern 搜尋指定字串樣式
n 跳至下一個搜尋結果
q 離開 man 手冊頁

Man 手冊頁章節分類

Man 手冊頁共分為以下幾個章節：

  1. 使用者指令（User commands）
  2. 系統呼叫（System calls）
  3. 函式庫函式（Library functions）
  4. 特殊檔案（裝置檔案）
  5. 檔案格式與設定檔（File formats）
  6. 遊戲（Games）
  7. 雜項（Miscellaneous）
  8. 系統管理指令（System administration commands）

若要存取特定章節的手冊頁：

man 5 passwd    # 檢視 passwd 檔案格式說明
man 1 passwd    # 檢視 passwd 指令說明

Info 文件頁（Info Pages）

部分指令提供更詳細的 Info 格式文件：

info command_name

--help 選項

大多數指令都支援 --help 選項，可快速檢視使用摘要：

ls --help
mkdir --help

/usr/share/doc 中的文件

套件隨附的額外詳細文件通常存放在此目錄：

ls /usr/share/doc/
💡 提示

使用 man -k keyword 可依關鍵字搜尋相關指令。例如：man -k network

📝 練習題

第 1 題：哪一個鍵盤快捷鍵可以切換到第 3 個虛擬主控台？

  • A) Ctrl+Alt+F1
  • B) Ctrl+Alt+F2
  • C) Ctrl+Alt+F3
  • D) Alt+F3
解答：C) Ctrl+Alt+F3
虛擬主控台 1 至 6 可透過 Ctrl+Alt+F1 到 Ctrl+Alt+F6 進行切換。

第 2 題：哪一個指令可以建立 4096 位元 RSA 加密的 SSH 金鑰對？

  • A) ssh-keygen
  • B) ssh-keygen -t rsa
  • C) ssh-keygen -t rsa -b 4096
  • D) ssh-create-key -rsa 4096
解答：C) ssh-keygen -t rsa -b 4096
-t 旗標用來指定金鑰類型（rsa），-b 則用來指定金鑰位元數（4096）。

第 3 題：哪一個指令可以顯示 passwd 指令的使用手冊？

  • A) help passwd
  • B) man passwd
  • C) info passwd
  • D) passwd --man
解答：B) man passwd
man 指令可用於顯示各個指令與系統呼叫的線上手冊（Manual Pages）。

第 4 題：Bash 提示字元中的 ~ 符號代表什麼？

  • A) 根目錄
  • B) 家目錄
  • C) 目前目錄
  • D) 上層目錄
解答：B) 家目錄
波浪號（~）是目前使用者家目錄的簡寫表示法。

第 5 題：哪一個按鍵組合可以取消終端機中正在執行的指令？

  • A) Ctrl+X
  • B) Ctrl+C
  • C) Ctrl+Z
  • D) Ctrl+D
解答：B) Ctrl+C
Ctrl+C 會傳送中斷訊號以取消目前正在執行的指令。Ctrl+D 用於結束並離開 Shell，而 Ctrl+Z 則會將程序暫停。
