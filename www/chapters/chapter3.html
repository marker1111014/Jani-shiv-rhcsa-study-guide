管理本機使用者與群組

學習建立、修改與刪除使用者帳號及群組。掌握密碼原則、使用者設定檔， 以及多使用者 Linux 系統中有效的使用者管理策略。

📋 本章目錄

  • 簡介
  • 了解使用者帳號
  • 管理使用者帳號
  • 管理群組帳號
  • 密碼管理
  • 練習題

🎯 簡介

使用者與群組管理是 Linux 安全性與系統組織的基石。每個程序都會以特定使用者的身分執行， 而檔案與系統資源的存取也都是透過使用者與群組權限來加以控管。

在本章中，您將學會：

  • 建立與管理本機使用者帳號
  • 設定使用者屬性與家目錄
  • 管理群組成員資格
  • 設定與強制執行密碼原則
  • 了解關鍵設定檔（/etc/passwd、/etc/shadow、/etc/group）

👤 了解使用者帳號

使用者帳號組成要素

Linux 中的每個使用者帳號皆包含以下要素：

  • 使用者名稱（Username）：使用者的唯一識別名稱
  • UID：使用者 ID 編號（數值識別碼）
  • 主要群組（Primary Group）：預設所屬群組（GID）
  • 家目錄（Home Directory）：使用者的個人工作空間
  • 登入 Shell（Login Shell）：預設的命令直譯器
  • 密碼（Password）：經加密的身份驗證憑證

使用者類型

使用者類型 UID 範圍 用途說明
Root 0 超級使用者（擁有完整系統存取權限）
系統使用者（System） 1-999 系統服務帳號（Daemons）
一般使用者（Regular） 1000+ 一般實體使用者

關鍵設定檔

/etc/passwd

包含使用者的基本帳號資訊：

student:x:1000:1000:Student User:/home/student:/bin/bash
│       │ │    │    │            │             │
│       │ │    │    │            │             └─ 登入 Shell
│       │ │    │    │            └─ 家目錄
│       │ │    │    └─ GECOS（備註欄位）
│       │ │    └─ 主要群組 ID (GID)
│       │ └─ 使用者 ID (UID)
│       └─ 密碼（x 表示加密密碼儲存在 /etc/shadow）
└─ 使用者名稱

/etc/shadow

儲存加密後的密碼與密碼效期原則：

student:$6$random$hash:18900:0:99999:7:::
│       │                │     │ │     │
│       │                │     │ │     └─ 密碼到期前警告天數
│       │                │     │ └─ 密碼最長有效天數
│       │                │     └─ 密碼最短變更間隔天數
│       │                └─ 上次密碼變更日期
│       └─ 加密後的密碼
└─ 使用者名稱

/etc/group

定義系統群組與其成員清單：

developers:x:2000:alice,bob,charlie
│          │ │    │
│          │ │    └─ 群組成員
│          │ └─ GID
│          └─ 密碼欄位（通常為 x 或留空）
└─ 群組名稱

👥 管理使用者帳號

建立使用者

useradd 指令

# 基本建立使用者
sudo useradd john

# 指定 UID 建立使用者
sudo useradd -u 1500 jane

# 指定家目錄建立使用者
sudo useradd -d /custom/home/path alice

# 指定登入 Shell 建立使用者
sudo useradd -s /bin/zsh bob

# 建立不附帶家目錄的使用者
sudo useradd -M serviceaccount

# 建立時加上備註說明
sudo useradd -c "John Doe" john

# 建立時加入指定的附屬群組
sudo useradd -G developers,admins charlie

# 完整範例
sudo useradd -u 1501 -g users -G developers,docker -c "Alice Developer" -s /bin/bash alice
📘 注意

預設情況下，useradd 會自動建立家目錄、指派下一個可用的 UID，並將 /bin/bash 設為預設登入 Shell。

修改使用者

usermod 指令

# 變更使用者名稱
sudo usermod -l newname oldname

# 變更 UID
sudo usermod -u 2000 john

# 變更並搬移家目錄內容
sudo usermod -d /new/home -m john

# 變更登入 Shell
sudo usermod -s /bin/zsh john

# 加入至附屬群組
sudo usermod -aG docker,wheel john

# 設定帳號到期日
sudo usermod -e 2025-12-31 john

# 鎖定帳號
sudo usermod -L john

# 解鎖帳號
sudo usermod -U john
⚠️ 警告

新增附屬群組時請務必使用 -aG。若只使用 -G，將會覆蓋並取代該使用者原本所有的附屬群組！

刪除使用者

userdel 指令

# 刪除使用者（保留家目錄）
sudo userdel john

# 刪除使用者並一併移除家目錄
sudo userdel -r john

# 強制刪除（即使使用者目前處於登入狀態）
sudo userdel -f john

檢視使用者資訊

# 檢視使用者詳細資訊
id john

# 檢視目前的使用者
whoami

# 檢視目前已登入的使用者
who

# 檢視使用者所屬群組
groups john

# 檢視最後一次登入資訊
lastlog -u john

操作步驟：建立完整的使用者帳號

  1. 使用指定選項建立使用者： 
    sudo useradd -u 1600 -c "Developer Account" -s /bin/bash developer
  2. 設定使用者密碼： 
    sudo passwd developer
  3. 加入至附屬群組： 
    sudo usermod -aG wheel,developers developer
  4. 驗證帳號設定： 
    id developer
grep developer /etc/passwd
  5. 測試登入： 
    su - developer

👨‍👩‍👧‍👦 管理群組帳號

建立群組

groupadd 指令

# 建立一般群組
sudo groupadd developers

# 指定 GID 建立群組
sudo groupadd -g 5000 admins

# 建立系統群組
sudo groupadd -r sysgroup

修改群組

groupmod 指令

# 重新命名群組
sudo groupmod -n newname oldname

# 變更 GID
sudo groupmod -g 6000 developers

刪除群組

groupdel 指令

# 刪除群組
sudo groupdel developers
⚠️ 警告

如果某個群組目前是任何使用者的主要群組（Primary Group），您將無法直接刪除它。請先變更該使用者的主要群組後再執行刪除。

管理群組成員資格

# 將使用者加入群組
sudo gpasswd -a username groupname

# 將使用者從群組中移除
sudo gpasswd -d username groupname

# 設定群組管理員
sudo gpasswd -A admin1,admin2 groupname

# 直接設定群組成員名單
sudo gpasswd -M user1,user2,user3 groupname

其他替代方法

# 使用 usermod（附加至群組）
sudo usermod -aG group1,group2 username

# 檢視指定群組的成員
getent group groupname

# 檢視系統上的所有群組
getent group

🔐 密碼管理

設定密碼

passwd 指令

# 為目前使用者設定密碼
passwd

# 為指定使用者設定密碼（以 root 身分執行）
sudo passwd john

# 從標準輸入設定密碼（常用於自動化腳本）
echo "newpassword" | sudo passwd --stdin john

# 強制使用者於下次登入時變更密碼
sudo passwd -e john

# 鎖定使用者帳號
sudo passwd -l john

# 解鎖使用者帳號
sudo passwd -u john

# 清除密碼（危險操作！）
sudo passwd -d john

密碼效期管理

chage 指令

# 檢視密碼效期資訊
sudo chage -l john

# 設定密碼最長有效天數
sudo chage -M 90 john

# 設定密碼最短變更間隔天數
sudo chage -m 7 john

# 設定密碼到期前警告天數
sudo chage -W 14 john

# 設定帳號到期日
sudo chage -E 2025-12-31 john

# 強制立即變更密碼
sudo chage -d 0 john

# 設定密碼到期後的帳號寬限停用天數
sudo chage -I 30 john

範例：完整的密碼原則

# 設定完整的密碼效期原則
sudo chage -M 90 -m 7 -W 14 -I 30 john

# 參數說明：
# -M 90:  密碼將於 90 天後到期
# -m 7:   變更密碼的最短間隔為 7 天
# -W 14:  密碼到期前 14 天開始警告使用者
# -I 30:  密碼到期 30 天後若仍未變更則鎖定帳號

預設密碼原則

/etc/login.defs

為新建的使用者設定預設密碼原則：

# 編輯 /etc/login.defs
PASS_MAX_DAYS   90
PASS_MIN_DAYS   7
PASS_MIN_LEN    8
PASS_WARN_AGE   14
💡 提示

/etc/login.defs 中的密碼原則僅適用於設定修改後才建立的新使用者；現有使用者必須透過 chage 指令另行更新。

密碼品質要求

透過 PAM（Pluggable Authentication Modules）設定密碼複雜度要求：

# 編輯 /etc/security/pwquality.conf
minlen = 12
dcredit = -1    # 至少包含 1 個數字
ucredit = -1    # 至少包含 1 個大寫字母
lcredit = -1    # 至少包含 1 個小寫字母
ocredit = -1    # 至少包含 1 個特殊字元
difok = 3       # 與舊密碼至少需有 3 個字元不同

📝 練習題

第 1 題：root 使用者的 UID 是多少？

  • A) 1
  • B) 0
  • C) 1000
  • D) 999
解答：B) 0
root 使用者的 UID 永遠為 0；一般使用者的 UID 通常從 1000 開始編號。

第 2 題：哪一個檔案負責儲存加密後的使用者密碼？

  • A) /etc/passwd
  • B) /etc/shadow
  • C) /etc/group
  • D) /etc/security
解答：B) /etc/shadow
/etc/shadow 負責儲存加密後的密碼與密碼效期資訊。為了確保安全性，該檔案僅限 root 讀取。

第 3 題：如何在不移除現有群組的情況下，將使用者加入新的附屬群組？

  • A) usermod -G groups user
  • B) usermod -aG groups user
  • C) useradd -G groups user
  • D) groupadd -u user groups
解答：B) usermod -aG groups user
搭配 -G 使用 -a（附加，append）旗標，可在不移除現有群組成員資格的情況下新增附屬群組。

第 4 題：哪一個指令可以強制使用者在下次登入時變更密碼？

  • A) passwd -e user
  • B) chage -d 0 user
  • C) usermod -f user
  • D) A 與 B 皆可
解答：D) A 與 B 皆可
passwd -e 與 chage -d 0 皆會讓密碼立即過期，藉此強制使用者於下次登入時變更密碼。

第 5 題：指令 'userdel -r john' 的作用是什麼？

  • A) 刪除使用者但保留家目錄
  • B) 刪除使用者並一併刪除家目錄
  • C) 重新命名該使用者
  • D) 鎖定該使用者帳號
解答：B) 刪除使用者並一併刪除家目錄
-r 選項會在刪除使用者帳號的同時，一併移除該使用者的家目錄與郵件佇列（Mail Spool）。
